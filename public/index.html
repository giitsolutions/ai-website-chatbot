What the bot has read

–Pages read
–Text sections
–Menu buttons clicked

For websites whose menu is buttons, not links. Use only on a website you own or manage. Buttons that look like actions (sign up, pay, delete…) are never clicked, and nothing can be sent while clicking. Takes effect the next time the website is read.

Last read

Read chosen pages

Read and index only these pages of this website (one address per line, up to 10) without crawling the whole website — for example a new page, or a page that failed. The same checks apply as in a full crawl (same website, robots.txt, safe addresses). A page that fails keeps the version indexed earlier.

When the bot can't answer

When the chatbot cannot answer from this website's information, visitors see a form to send their question. It is saved in the Enquiries tab and emailed to this address. Without an address, questions are only saved in the Enquiries tab.

Reading limits

How many pages to read each time, from 1 to 50.

Remove this chatbot

Each action first shows what it will remove and asks you to type the website's domain. Remove website content deletes the indexed pages and the crawl report; the chatbot, its settings and its documents stay. Delete chatbot removes everything of this chatbot. Neither can be undone. To remove a single page, use Remove in the table under Last read; to remove one document, use the Documents tab.

Ask the questions your visitors would ask. Answers come only from the indexed pages; each answer links to the page it used.

Explain an answer

Runs a question through the same pipeline as the chat and shows why it was answered or not: which sections were retrieved, which were sent to the model, and which check produced a fallback. Asking the model takes as long as a normal answer.

Documents

Add documents the chatbot should know as well as the website, for example procedures, manuals or policies. Answers cite the document and page.

Questions visitors sent

Appearance

One address per line. Leave empty to allow any website. This stops other websites from embedding your chatbot in visitors' browsers; it is not a password.
